# Design seed

Inputs for the v2 design system (`packages/ui`), shared by the dashboard and the website (inboxangel.io):

- `design-context.md`: brand personality, palette rules (sky `#60A5FA` as a fill with navy text; `--brand-ink` for text), typography (Geist Sans / Geist Mono), principles and WCAG target.
- `site-globals.css`: the website's current light/dark token set and Tailwind 4 setup (source of truth for token values).
- `brand/`: the Inbox Angel logo marks (simple, and a 3-colour SVG Tiny PS draft for BIMI).
